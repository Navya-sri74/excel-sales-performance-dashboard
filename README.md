Excel Sales Performance Dashboard

Project Overview

This project focuses on analyzing sales data and creating an interactive dashboard using Microsoft Excel. The dashboard helps understand sales performance, profit trends, product performance, regional sales, and salesperson performance.

Objectives

- Analyze overall sales and profit.
- Compare sales across different regions.
- Identify top-performing products.
- Evaluate salesperson performance.
- Analyze quantity sold by category.

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Interactive Dashboard

Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Average Order Value
- Profit Margin

Dashboard Features

- Sales by Region
- Profit by Region
- Profit by Product
- Salesperson Performance
- Sales by Product
- Quantity Sold by Category
- Interactive Product and Region Slicers

Key Insights

- Compared sales performance across four regions.
- Identified product-wise sales and profit contributions.
- Analyzed individual salesperson performance.
- Evaluated category-wise quantity sold.

Conclusion

This project helped me improve my practical skills in Microsoft Excel, data analysis, Pivot Tables, Pivot Charts, and interactive dashboard creation. It provides useful insights into business sales performance and supports better decision-making.
